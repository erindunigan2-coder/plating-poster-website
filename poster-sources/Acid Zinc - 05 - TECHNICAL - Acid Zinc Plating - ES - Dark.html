Solución de Problemas 8 problemas comunes

Quemado en Alta CD

pH muy bajo; zinc muy bajo; exceso de secundario

→ Subir pH; agregar zinc; verificar Celda Hull

Depósito Opaco

Abrillantador primario agotado; temp. muy baja; orgánicos

→ Agregar primario por amp-hr; verificar temp.; tratar con carbón

Picaduras

Transportador bajo; agitación deficiente; piezas sucias

→ Agregar transportador; aumentar aire; verificar limpieza

Opacidad

Contaminación de hierro; orgánicos; exceso de transportador

→ Analizar Fe; tratar con carbón; verificar transportador; dummy

Rayas / Puntos Oscuros

Contaminación de Cu o Pb; lodos del ánodo

→ Analizar metales; dummy; verificar bolsas de ánodo

Rugosidad

Partículas; Pb; filtración deficiente

→ Verificar filtro; analizar Pb; embolsar ánodos

Desprendimiento

Estrés excesivo; desequilibrio de abrillantadores

→ Prueba de doblez en Celda Hull; reducir primario; analizar Cu

Bajo Poder de Penetración

Normal para zinc ácido (3:1–5:1); pH muy bajo

→ Optimizar pH; aceptar cierta variación vs alcalino

⚠ Seguridad — Baño de Zinc Ácido Cloruro
Solución ácida de cloruro (pH 4.8–5.8) — causa quemaduras. Rectificador = alto amperaje — riesgo de descarga/arco eléctrico. La agitación por aire genera niebla de cloruro de zinc — se requiere ventilación. LOTO para todo mantenimiento de rectificadores. El cloruro es corrosivo — use tanques de PP/PVC, no acero al carbón.
